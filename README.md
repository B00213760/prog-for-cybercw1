## Coursework Overview

This program is Task 2 of my Programming for Cyber Security Coursework 1.

The Security Event Logger records login attempts made by a user. It asks for a username and password and continues until the correct login details are entered.

Each login attempt is recorded with an event ID, username, IP address, event type and timestamp.

The program records both successful and failed login attempts.


## Program Features

- Asks the user to enter a username and password.
- Checks the entered details against stored login credentials.
- Records both successful and failed login attempts.
- Assigns a unique event ID to each attempt.
- Records the username, IP address, event type and timestamp.
- Displays the security event log after each attempt.
- Continues asking for login details until authentication is successful.

## How to Run the Program

1. Open the project in Visual Studio Code.
2. Open the terminal.
3. Make sure Python 3 is installed.
4. Run the following command:
   python3 security-event-logger.py

5. Enter a username and password when prompted.
6. The program will display a security event log for each login attempt.
7. The program will continue until the correct login details are entered.
