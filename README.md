## Coursework Overview
This task involves creating reusable Python functions for basic cyber security checks. The functions are stored in security_tools.py and imported into main.py.

## Program Features
- Checks password strength using length, uppercase and lowercase letters, numbers and special characters.
- Validates IPv4 addresses.
- Generates random strong passwords between 10 and 16 characters.
- Suggests a strong password when the user enters a weak password.

## How to Run the Program
Run the following command in the terminal:

python3 main.py

## Testing
The program was tested using strong and weak passwords, valid and invalid IP addresses and random password generation.
