## Coursework Overview

This program is Task 3 of my Programming for Cyber Security Coursework 1.

The IP Address Validator asks the user to enter an IPv4 address and checks whether it meets basic IPv4 formatting requirements.

The program displays whether the entered IP address is valid or invalid.

## Program Features

- Asks the user to enter an IP address.
- Removes extra spaces from the beginning and end of the input.
- Checks that the IP address contains four sections separated by dots.
- Checks that each section contains only numbers.
- Checks that each number is between 0 and 255.
- Displays whether the IP address is valid or invalid.

## How to Run the Program

1. Open the project in Visual Studio Code.
2. Open the terminal.
3. Make sure Python 3 is installed.
4. Run the following command: `python3 ip-address-validator.py`
5. Enter an IP address when prompted.
6. The program will display whether the IP address is valid or invalid.

## Testing

The program was tested using valid and invalid IP addresses, including addresses with missing sections, numbers outside the allowed range, letters and extra spaces.
